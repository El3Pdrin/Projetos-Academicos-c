
# Projetos Acadêmicos em C

Repositório criado para armazenar e apresentar meus projetos desenvolvidos durante os estudos de Engenharia de Software na Universidade Veiga de Almeida (UVA).

## Sobre os projetos

Os exercícios têm como objetivo desenvolver minha lógica de programação e conhecimentos na linguagem C.

## Projetos desenvolvidos

| Projeto        | Conceitos praticados |                 
|----------------|----------------------------------------|
| MédiaAluno     | Variáveis, entrada de dados e cálculos |
| ParÍmpar       | Condicionais e operador módulo |
| MaiorMenor     | Comparações e condicionais |
| ConversaoDólar | Operações matemáticas |
| ControleCaixa  | Condicionais, porcentagem e cálculos |

## Tecnologias utilizadas

- Linguagem C
- Dev-C++
